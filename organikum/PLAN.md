## 1. Was hier entsteht — und was nicht

**Entsteht:** ein vollständiges, deutschsprachiges Lehrbuch der präparativen
organischen Chemie im Zuschnitt eines Grundpraktikums — Arbeitstechniken,
theoretische Grundlagen, rund 200 Arbeitsvorschriften, Identifizierungsanalytik,
Reagenzien- und Gefahrstoffanhang, Tabellen, Register. Umfang, Gliederung, Satzbild
und Anmutung entsprechen dem genannten Standardwerk: Teile A–G, Kapitel D.1–D.9,
Vorschriften mit Ansatz, Durchführung, Ausbeute, Kenndaten, Gefahrenhinweis.

**Entsteht nicht:** ein Nachdruck oder eine Reproduktion des Originaltextes. Der
Text des Organikum ist urheberrechtlich geschützt; wörtliche Übernahmen sind
unzulässig. Geschrieben wird also eine eigenständige Ausgabe in derselben Gattung:
gleiche Ordnung, gleiche Kapitelfolge, gleicher Aufbau jeder Vorschrift — eigener
Text, eigene Versuchsbeschreibungen, geprüfte Stoffdaten. Fachliche Substanz
(Naturgesetze, Reaktionen, Meßwerte, Sicherheitsregeln) ist frei verwendbar.

Zwei Punkte zur Klarheit, bevor Text entsteht:

1. **Titel.** „Organikum" ist für ein Praktikumsbuch dieses Zuschnitts der
   etablierte Name und liegt als Marke beim Verlag. Ich führe ihn als Arbeitstitel;
   für eine Veröffentlichung empfehle ich einen eigenen Titel (z. B.
   „Praktikum der präparativen Organischen Chemie"). Auf dem Titelblatt der
   Arbeitsfassung steht der Arbeitstitel, das Impressum weist die Eigenständigkeit aus.
2. **Stoffdaten.** Siedepunkte, Schmelzpunkte, Dichten, Brechungsindizes und
   Ausbeuten werden gegen Standardwerte geprüft. Wo ich unsicher bin, steht ein
   Literaturhinweis statt einer erfundenen Zahl.

## 3. Handwerkszeug — läuft bereits

* **Satz:** Typst über `@myriaddreamin/typst-ts-node-compiler` (reines Node, keine
  Systeminstallation). Buchformat 168 × 240 mm, Bundsteg, Kolumnentitel,
  Teile A–G mit eigener Kapitelzählung (A.1, D.2 …), automatisches Inhaltsverzeichnis,
  Fußnoten, laufende Abbildungs- und Tabellenzählung je Teil (Abb. D.1, Tab. D.3).
* **Strukturformeln:** RDKit zeichnet Skelettformeln aus SMILES
  (`data/strukturen.json` → `bilder/strukturen/*.svg`), einfarbig, vektorgenau.
* **Formelsatz:** Reaktionsgleichungen mit Bedingungen über dem Pfeil, Indizes,
  Einheiten (g·cm<sup>−3</sup>), Gleichgewichte.
* **Bau und Kontrolle:** `node tools/build.mjs` (PDF), `node tools/stats.mjs`
  (Wörter, Vorschriften, Seitenprognose), Sichtprüfung als PNG je Seite.

Befehlsfolge:

```bash
cd organikum
npm install
python3 tools/strukturen.py     # Strukturformeln
node tools/build.mjs            # PDF nach ausgabe/
node tools/stats.mjs            # Kennzahlen
```

## 5. Qualitätsregeln

1. **Fachlich belastbar** — geprüfte Stoffdaten, plausible Ansätze, Ausbeuten im
   realistischen Bereich; keine erfundenen Meßwerte.
2. **Sicherheit** — jede Vorschrift mit Gefahrenhinweis (H-/P-Sätze, Entsorgung),
   Teil G mit Erste-Hilfe-Maßnahmen; Sicherheitsangaben auf heutigem Stand, mit
   Hinweis auf die historische Fassung von 1998.
3. **Konsistenz** — einheitliche Nomenklatur (IUPAC, deutscher Trivialname in
   Klammern), gleiche Einheiten, gleiche Vorschriftenstruktur, durchlaufende
   Numerierung.
4. **Satzbild** — keine Überläufe, keine verwaisten Überschriften, Abbildungen mit
   Quellenzeile, Register aus dem Satz erzeugt, PDF mit Lesezeichen und Metadaten.
5. **Nachvollziehbar** — Quelltext offen im Repo, Build reproduzierbar, jede
   Vorschrift einzeln auffindbar.
